# Part I. Quant 面试题：Color Balls

## 1. 题目描述

有 (n)
个球，初始时每个球的颜色都不同。每一步独立、均匀地选择两个不同的位置
(i,j)，并将位置 (i) 的球改成位置 (j) 的颜色。

问：所有球最终变成同一种颜色所需操作次数的期望是多少？

这里选择的是**有序位置对** ((i,j))，其中
(i`\ne`{=tex}j)，每个有序对概率均为
(1/\[n(n-1)\])。操作中改变颜色的是第一个位置 (i)。

结论：

\[ `\boxed{\mathbb E[T]=(n-1)^2}`{=tex}. \]

直接记录每种颜色的球数当然可以做递推，但状态种类很多。下面用随机矩阵将问题降为一维马尔可夫链。

## 2. 单步操作写成矩阵

将颜色标签编码为向量

\[ x=(x_1,`\ldots`{=tex},x_n)\^`\top`{=tex}. \]

记 (e_i) 为第 (i) 个标准基向量。定义

\[ R\_{ij}=I+e_i(e_j-e_i)\^`\top`{=tex},`\qquad`{=tex}i`\ne`{=tex}j. \]

那么

\[ (R\_{ij}x)\_i=x_i+(x_j-x_i)=x_j, \]

其他坐标不变。因此 (R\_{ij}) 正好表示"位置 (i) 复制位置 (j) 的颜色"。

令 (A_t) 表示第 (t) 步随机选出的矩阵。则 (A_1,A_2,`\ldots`{=tex})
独立同分布，并且

\[ P(A_t=R\_{ij})=`\frac1{n(n-1)}`{=tex}. \]

## 3. 原过程：左乘矩阵

定义

\[ M_0=I,`\qquad`{=tex}M_t=A_tM\_{t-1}. \]

展开：

\[ M_t=A_tA\_{t-1}`\cdots`{=tex}A_1. \]

若初始颜色向量为 (x_0=(1,2,`\ldots`{=tex},n)\^`\top`{=tex})，则
(x_t=M_tx_0)。

每个 (A_t) 都将某一行替换成另一行，所以 (M_t) 的每一行始终恰好有一个
1，其余元素为 0。第 (i) 行记录当前第 (i) 个位置的颜色来自哪个初始位置。

由于初始颜色各不相同，

\[ `\text{所有球同色}`{=tex}`\iff`{=tex}M_t`\text{ 的所有行相同}`{=tex}
`\iff`{=tex}`\operatorname{rank}`{=tex}(M_t)=1. \]

定义首次吸收时间

\[ T_M=`\inf`{=tex}{t`\ge0`{=tex}:`\operatorname{rank}`{=tex}(M_t)=1}.
\]

这就是要求的随机变量 (`\mathbb`{=tex}E\[T_M\])。

### 为什么直接研究秩很难？

左乘会替换一行。秩是否下降，取决于被替换的那一行是否代表某种颜色的唯一来源。仅知道当前秩
(k)，通常无法确定下一步降秩的概率；因此原过程的秩不是容易处理的封闭状态。

## 4. 构造右乘辅助过程

主动定义另一个过程：

\[ N_0=I,`\qquad`{=tex}N_t=N\_{t-1}A_t, \]

所以

\[ N_t=A_1A_2`\cdots`{=tex}A_t. \]

注意：这不是将矩阵乘法交换，而是另行构造一个辅助过程。一般来说，同一次随机实验中
(M_t`\ne`{=tex}N_t)。

### 关键引理：固定时刻同分布

由于 (A_1,`\ldots`{=tex},A_t)
独立同分布，随机矩阵序列的联合分布在反序后不变：

\[ (A_1,`\ldots`{=tex},A_t)`\overset`{=tex}d=(A_t,`\ldots`{=tex},A_1).
\]

将这两个随机序列分别代入矩阵乘积映射，可得

\[ `\boxed{M_t=A_t\cdots A_1\overset d=A_1\cdots A_t=N_t}`{=tex}. \]

这里使用的是 i.i.d. 随机序列的反序对称性，而不是矩阵乘法的交换律。

### 为什么固定时刻同分布足够？

定义

\[ T_N=`\inf`{=tex}{t`\ge0`{=tex}:`\operatorname{rank}`{=tex}(N_t)=1}.
\]

两个过程的秩都不会增加，因此秩达到 1 后会一直保持 1。于是

\[ {T_M`\le`{=tex}t}={`\operatorname{rank}`{=tex}(M_t)=1}, \]

\[ {T_N`\le`{=tex}t}={`\operatorname{rank}`{=tex}(N_t)=1}. \]

利用 (M_t`\overset`{=tex}d=N_t)：

\[

```{=tex}
\begin{aligned}
P(T_M\le t)
&=P(\operatorname{rank}(M_t)=1)\\
&=P(\operatorname{rank}(N_t)=1)\\
&=P(T_N\le t).
\end{aligned}
```
\]

所以

\[ `\boxed{T_M\overset d=T_N}`{=tex}, `\qquad`{=tex}
`\boxed{\mathbb E[T_M]=\mathbb E[T_N]}`{=tex}. \]

一般而言，两个过程每个固定时刻同分布，并不足以推出首次到达时间同分布；本题成立的关键是目标状态具有吸收性。

## 5. 右乘如何使状态变得简单？

由

\[ R\_{ij}=I+e_i(e_j-e_i)\^`\top`{=tex} \]

可得

\[ N\_{t+1}=N_tR\_{ij} =N_t+N_te_i(e_j-e_i)\^`\top`{=tex}. \]

记 (v_i=N_te_i) 为 (N_t) 的第 (i) 列。右乘 (R\_{ij}) 的效果是：

-   第 (i) 列变为零列；
-   第 (j) 列变为原第 (j) 列加原第 (i) 列；
-   其他列不变。

由于 (N_t) 的每一行仍恰好有一个
1，不同非零列的支撑互不相交，因此非零列线性无关：

\[ `\operatorname{rank}`{=tex}(N_t)=#{`\text{非零列}`{=tex}}. \]

令

\[ K_t=`\operatorname{rank}`{=tex}(N_t). \]

也就是 (N_t) 的非零列数。

令 (z_i=1) 表示第 (i) 列非零，(z_i=0) 表示第 (i) 列为零。则

\[ K_t=`\sum`{=tex}\_{i=1}\^n z_i. \]

一次右乘只会在第 (i,j) 列都非零时使非零列数减少 1。因此

\[ K\_{t+1}=K_t-z\_{I\_{t+1}}z\_{J\_{t+1}}, \]

其中 ((I\_{t+1},J\_{t+1})) 是下一步均匀抽取的有序位置对。

## 6. 推导一维马尔可夫链的转移概率

给定完整矩阵 (N_t)，所有 (z_i) 都已确定。若 (K_t=k)，则

\[

```{=tex}
\begin{aligned}
P(K_{t+1}=k-1\mid N_t)
&=\frac1{n(n-1)}\sum_{i\ne j}z_iz_j\\
&=\frac{(\sum_i z_i)^2-\sum_i z_i^2}{n(n-1)}.
\end{aligned}
```
\]

因为 (z_i`\in`{=tex}{0,1})，所以 (z_i\^2=z_i)，而 (`\sum`{=tex}\_i
z_i=k)。因此

\[
`\boxed{ p_k=P(K_{t+1}=k-1\mid K_t=k) =\frac{k(k-1)}{n(n-1)}. }`{=tex}
\]

这个概率只依赖于 (k)，与完整矩阵的其他细节无关，所以 (K_t)
构成一维马尔可夫链：

\[ k`\longrightarrow`{=tex}

```{=tex}
\begin{cases}
k-1,&\text{概率 }\dfrac{k(k-1)}{n(n-1)},\\[6pt]
k,&\text{概率 }1-\dfrac{k(k-1)}{n(n-1)}.
\end{cases}
```
\]

初始状态 (K_0=n)，吸收状态为 (K=1)。

## 7. 计算吸收时间期望

令 (E_k) 表示从状态 (k) 出发，到达 1 的期望步数。边界条件为

\[ E_1=0. \]

从状态 (k`\ge2`{=tex}) 出发，先走一步：

\[ E_k=1+p_kE\_{k-1}+(1-p_k)E_k. \]

整理得到

\[ E_k-E\_{k-1}=`\frac1{p_k}`{=tex} =`\frac{n(n-1)}{k(k-1)}`{=tex}. \]

于是

\[

```{=tex}
\begin{aligned}
E_n
&=\sum_{k=2}^{n}(E_k-E_{k-1})\\
&=n(n-1)\sum_{k=2}^n\frac1{k(k-1)}\\
&=n(n-1)\sum_{k=2}^n
\left(\frac1{k-1}-\frac1k\right)\\
&=n(n-1)\left(1-\frac1n\right)\\
&=\boxed{(n-1)^2}.
\end{aligned}
```
\]

### 本题值得记住的套路

1.  把单步操作表示为随机矩阵。
2.  原过程的状态统计量不封闭时，尝试构造一个等分布的辅助过程。
3.  用 i.i.d. 随机矩阵的反序对称性证明固定时刻同分布。
4.  利用吸收性将固定时刻同分布提升为吸收时间同分布。
5.  在辅助过程中寻找封闭的一维状态，再用首次步分析求期望。

# Part II. Codeforces 2219C --- Coloring a Red Black Tree

-   **OJ：** [Codeforces
    2219C](https://codeforces.com/problemset/problem/2219/C)
-   **难度：** 2300
-   **标签：** 树形 DP、贪心、期望、排序
-   **注意：**
    这道题的单步操作同样能写成复制矩阵，但其节点选择由我们控制，随机矩阵不再是
    i.i.d. 序列，因此不能直接套用 Color Balls 的时间反序证明。

## 1. 题目描述（中文整理）

给定一棵有 (n) 个节点的树，以及长度为 (n) 的二进制字符串 (s)。

-   (s_i=1)：节点 (i) 初始为红色；
-   (s_i=0)：节点 (i) 初始为黑色。

保证至少有一个红色节点。

每次操作：

1.  主动选择一个节点 (a)；
2.  从 (a) 的所有邻居中等概率随机选择一个节点 (b)；
3.  将节点 (a) 的颜色改为节点 (b) 的颜色。

注意：被改变颜色的是主动选择的节点 (a)，而不是随机选出的邻居 (b)。

可以执行任意多次操作（也可以一次都不执行）。求在最优策略下，将整棵树全部变成红色所需操作次数的最小期望。

### 输入

每组输入包含多组测试用例。

-   第一行是测试用例数 (t)。
-   每组首先输入 (n)，其中
    (1`\le`{=tex}n`\le 2`{=tex}`\times10`{=tex}\^5)。
-   输入长度为 (n) 的二进制字符串 (s)。
-   接下来输入 (n-1) 条边。
-   所有测试用例的 (n) 之和不超过 (2`\times10`{=tex}\^5)。

### 输出

每组输出最小期望操作次数。绝对误差或相对误差不超过 (10\^{-6})。

原题：[Codeforces
2219C](https://codeforces.com/problemset/problem/2219/C)。

## 2. 与 Color Balls 的联系和区别

对一次指定的复制操作，仍可定义

\[ R\_{ab}=I+e_a(e_b-e_a)\^`\top`{=tex}. \]

所以从代数上说，两题都能用矩阵描述"一个位置复制另一个位置"。

但两题的随机机制不同：

-   Color Balls：每一步随机均匀选择整个位置对，矩阵序列 i.i.d.。
-   CF 2219C：我们主动选择节点 (a)，只有邻居 (b)
    是随机的；最优策略会依赖当前颜色状态。

因此 CF 2219C 不能直接使用 Color Balls
的时间反序对称性。它的关键是把期望转化成**决定黑色节点变红的先后顺序**，再用树形
DP 优化这个顺序。

## 3. 第一步：固定染红顺序，计算期望代价

我们不需要主动操作已经红色的节点，因为这样没有帮助。

考虑一个当前为黑色的节点 (u)。设它的度数为
(d_u)，在我们决定将它染红的时刻，已经有 (r_u) 个邻居为红色。

每次对 (u) 操作，它以概率

\[ p=`\frac{r_u}{d_u}`{=tex} \]

变红。如果没有成功，树上其他节点的颜色不会因为这次操作而改变，因此下一次对
(u) 操作时成功概率仍然是 (p)。

所需操作次数服从参数为 (p) 的几何分布，期望为

\[ `\boxed{\frac1p=\frac{d_u}{r_u}}`{=tex}. \]

因此，对于一个固定的染红顺序，总期望就是每个黑色节点的

\[ `\frac{\text{节点度数}}{\text{染红时已经红色的邻居数}}`{=tex} \]

之和。

如果
(r_u=0)，节点就无法被染红，所以任何有效顺序都必须保证每个黑色节点在轮到它时至少有一个红色邻居。

## 4. 第二步：把先后顺序转化为树形 DP

任选一个**初始红色节点**作为整棵树的根。这样所有初始红色节点都不需要付出染红代价。

对于每个节点 (u)，定义：

-   (f_u\^{`\text{before}`{=tex}})：在处理 (u) 的子树时，要求 (u)
    先于它的父节点变红的最小期望代价；
-   (f_u\^{`\text{after}`{=tex}})：要求 (u)
    晚于它的父节点变红的最小期望代价。

对于初始红色节点，(u)
从一开始就已为红色，因此其所有黑色子树都可以在父节点已经为红色的条件下独立处理：

\[
`\boxed{ f_u^{\text{before}} =f_u^{\text{after}} =\sum_{v\in\operatorname{child}(u)}f_v^{\text{after}}. }`{=tex}
\]

对于初始黑色节点 (u)，记子节点集合为 (C(u))，度数为 (d_u)。

先假设父节点为黑色，且要求 (u)
先于父节点变红。那么，必须先把至少一个子节点变红，否则 (u)
没有任何红色邻居，无法变红。

如果选择子节点集合 (S`\subseteq`{=tex}C(u)) 在 (u) 之前变红，那么：

-   \(S\) 中的子节点采用 (f_v\^{`\text{before}`{=tex}})；
-   其他子节点采用 (f_v\^{`\text{after}`{=tex}})；
-   \(u\) 染红时恰有 (\|S\|) 个红色子邻居，期望代价为 (d_u/\|S\|)。

所以

\[
`\boxed{ f_u^{\text{before}} = \min_{\substack{S\subseteq C(u)\\|S|\ge1}} \left[ \frac{d_u}{|S|} +\sum_{v\in S}f_v^{\text{before}} +\sum_{v\notin S}f_v^{\text{after}} \right]. }`{=tex}
\]

再假设父节点已经变红，要求 (u) 晚于父节点变红。即使没有子节点先变红，(u)
也至少有父节点这一个红色邻居。因此

\[
`\boxed{ f_u^{\text{after}} = \min_{S\subseteq C(u)} \left[ \frac{d_u}{|S|+1} +\sum_{v\in S}f_v^{\text{before}} +\sum_{v\notin S}f_v^{\text{after}} \right]. }`{=tex}
\]

对于以初始红色节点为根的整棵树，答案是

\[
`\boxed{ \sum_{v\in\operatorname{child}(root)} f_v^{\text{after}}. }`{=tex}
\]

这里的 before / after 仅表示节点变红的先后顺序，不是矩阵乘法的先后顺序。

## 5. 第三步：用排序优化对子集的枚举

直接枚举 (S) 是指数复杂度。

定义每个子节点 (v) 的增量

\[
`\Delta`{=tex}\_v=f_v^{`\text{before}`{=tex}}-f_v^{`\text{after}`{=tex}}.
\]

先把所有子节点都放在 (u) 之后处理，基础代价为

\[ B_u=`\sum`{=tex}\_{v`\in`{=tex}C(u)}f_v\^{`\text{after}`{=tex}}. \]

若将某个子节点 (v) 改为先于 (u) 变红，代价变化就是 (`\Delta`{=tex}\_v)。

假设选择 (q) 个子节点先变红。要使子树代价最小，只需选择
(`\Delta`{=tex}\_v) 最小的 (q) 个子节点。

把这些增量升序排序：

\[
`\Delta`{=tex}\_1`\le`{=tex}`\Delta`{=tex}\_2`\le`{=tex}`\cdots`{=tex}`\le`{=tex}`\Delta`{=tex}\_k,
\]

并定义前缀和

\[ P_q=`\sum`{=tex}\_{i=1}\^{q}`\Delta`{=tex}\_i,`\qquad`{=tex}P_0=0. \]

那么

\[
`\boxed{ f_u^{\text{before}} =B_u+\min_{1\le q\le k} \left(P_q+\frac{d_u}{q}\right) }`{=tex}
\]

以及

\[
`\boxed{ f_u^{\text{after}} =B_u+\min_{0\le q\le k} \left(P_q+\frac{d_u}{q+1}\right). }`{=tex}
\]

其中 (k) 是 (u) 的子节点数。若 (u)
为黑色叶节点，(f_u\^{`\text{before}`{=tex}}=+`\infty`{=tex})，因为父节点还黑时它没有红色邻居；而

\[ f_u\^{`\text{after}`{=tex}}=d_u \]

因为父节点已红，操作一次就能以概率 (1/d_u) 成功。

每个节点对子节点增量排序，所有节点总复杂度为

\[ `\boxed{O(n\log n)}`{=tex} \]

空间复杂度为 (O(n))。

## 6. C++17 参考实现

``` cpp
#include <bits/stdc++.h>
using namespace std;

using ld = long double;
const ld INF = 1e100L;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;

    cout << fixed << setprecision(12);

    while (T--) {
        int n;
        cin >> n;

        string s;
        cin >> s;

        vector<vector<int>> g(n);
        for (int i = 0; i < n - 1; ++i) {
            int u, v;
            cin >> u >> v;
            --u;
            --v;
            g[u].push_back(v);
            g[v].push_back(u);
        }

        int root = -1;
        for (int i = 0; i < n; ++i) {
            if (s[i] == '1') {
                root = i;
                break;
            }
        }

        vector<int> parent(n, -1), order;
        order.reserve(n);

        // Iterative DFS: avoid recursion depth problems on a long chain.
        vector<int> st = {root};
        parent[root] = root;

        while (!st.empty()) {
            int u = st.back();
            st.pop_back();
            order.push_back(u);

            for (int v : g[u]) {
                if (parent[v] != -1) continue;
                parent[v] = u;
                st.push_back(v);
            }
        }

        vector<ld> before(n, 0), after(n, 0);

        // Process children before parents.
        reverse(order.begin(), order.end());

        for (int u : order) {
            vector<int> children;
            for (int v : g[u]) {
                if (parent[v] == u) children.push_back(v);
            }

            if (s[u] == '1') {
                // Initially red: no cost to color u.
                ld sum = 0;
                for (int v : children) sum += after[v];
                before[u] = after[u] = sum;
                continue;
            }

            ld base = 0;
            vector<ld> delta;
            delta.reserve(children.size());
            int redChildren = 0;

            for (int v : children) {
                base += after[v];
                if (s[v] == '1') {
                    // Initially red child is already a red neighbor;
                    // it is not a scheduling choice.
                    ++redChildren;
                } else {
                    delta.push_back(before[v] - after[v]);
                }
            }

            sort(delta.begin(), delta.end());

            int k = (int)delta.size();
            vector<ld> pref(k + 1, 0);
            for (int i = 0; i < k; ++i) {
                pref[i + 1] = pref[i] + delta[i];
            }

            ld d = (ld)g[u].size();

            // u becomes red before its parent:
            // the parent is still black, but initially red children
            // already contribute redChildren red neighbors.
            before[u] = INF;
            for (int q = 0; q <= k; ++q) {
                int red = redChildren + q;
                if (red == 0) continue;
                before[u] = min(before[u], base + pref[q] + d / red);
            }

            // u becomes red after its parent:
            // its parent contributes one additional red neighbor.
            after[u] = INF;
            for (int q = 0; q <= k; ++q) {
                int red = redChildren + q + 1;
                after[u] = min(after[u], base + pref[q] + d / red);
            }
        }

        // The chosen root is initially red.
        ld ans = 0;
        for (int v : g[root]) {
            if (parent[v] == root) ans += after[v];
        }

        cout << ans << '\n';
    }

    return 0;
}
```

### 复杂度

-   每个节点对子节点的 (`\Delta`{=tex}\_v) 排序，总复杂度
    (O(n`\log`{=tex}n))。
-   树的遍历与 DP 合计 (O(n))。
-   空间复杂度 (O(n))。

注意：这是根据上述 DP 推导整理的参考实现，尚未在 Codeforces
上实际提交验证。正式使用前建议用官方样例及随机小树暴力对拍。

## 7. 本题的学习重点

这道题的核心不是随机矩阵反序，而是：

1.  固定染红顺序后，每个黑点的等待时间是几何分布，期望为 (d_u/r_u)。
2.  树形 DP 用"节点先于父亲 / 后于父亲"表示时间约束。
3.  选择哪些子节点先处理，变成选取若干个增量最小的子节点。
4.  排序和前缀和把子集枚举优化到 (O(n`\log`{=tex}n))。

两道题的共同点是都将颜色复制写成了代数操作，但真正可迁移的能力是：**识别哪些历史信息影响未来，并据此构造封闭状态。**
