&(1)F=\{a+b\sqrt[3]{2}+c\sqrt[3]{4}|a,b,c\in Q\}是数域\\
&(2)Q(\pi)是整环Q[\pi]的分式域\\
&(3)有限域Z_{2}[x]/(1+x+x^2)\\
&\\\\
&Prove(1):\\
&一种高级的证明方法:\\
&记h=a+b\sqrt[3]{2}+c\sqrt[3]{4}\\
&F对乘法封闭,h\in F\Rightarrow \\
&h,h^2,h^3,h^4\in F线性相关\\
&不妨设a\ne 0,\Rightarrow \\
&ah=-(bh^2+ch^3+dh^4)\\
&\Rightarrow ah^{-1}=-(b+ch+dh^2)\in F\\
&\\\\
&(通过证明矩阵可逆的证明方法)\\
&\\\\
&Q[x]的分式域\cong Q[\pi]\\
\end{aligned}
$

这确实是一个非常经典的抽象代数（或伽罗瓦理论）问题！你笔记中提到的第一种方法非常巧妙，它利用了有限维 $\mathbb{Q}$-线性空间中向量的线性相关性（本质上是证明有限维整环必然是域）。

而你想要补充的**通过矩阵可逆的证明方法**（也常被称为待定系数法或正则表达法），思路更加直接且具有构造性：它的核心目标是证明**任何一个非零元素的逆元素仍然可以表示为这种形式**。

以下是完整的证明过程：

### 证明 (2): 通过矩阵可逆性（待定系数法）

为了书写方便，我们记 $\alpha = \sqrt[3]{2}$。已知 $\alpha^3 = 2$，且该集合可以表示为 $F = \{a + b\alpha + c\alpha^2 \mid a,b,c \in \mathbb{Q}\}$。

因为 $F$ 显然对加法、减法和乘法封闭（乘法展开后，高次项 $\alpha^3$ 可以降次为 $2$，$\alpha^4$ 降次为 $2\alpha$），所以要证明 $F$ 是一个数域，我们只需要证明：**对于 $F$ 中的任意非零元素 $x$，其乘法逆元 $x^{-1}$ 也属于 $F$**。

**第一步：构造线性方程组**
设 $x = a + b\alpha + c\alpha^2$ 是 $F$ 中的任意非零元素（即 $a,b,c$ 不全为 $0$）。
假设它的逆元在 $F$ 中存在，且为 $y = x_1 + y_1\alpha + z_1\alpha^2$，其中 $x_1, y_1, z_1 \in \mathbb{Q}$。
根据逆元的定义，有 $x \cdot y = 1$。我们将它们相乘并展开：

$$(a + b\alpha + c\alpha^2)(x_1 + y_1\alpha + z_1\alpha^2) = 1$$

展开并利用 $\alpha^3 = 2$ 和 $\alpha^4 = 2\alpha$ 合并同类项：


$$ax_1 + ay_1\alpha + az_1\alpha^2 + bx_1\alpha + by_1\alpha^2 + 2bz_1 + cx_1\alpha^2 + 2cy_1 + 2cz_1\alpha = 1$$

将含有 $1$、$\alpha$、$\alpha^2$ 的项分别归类：

* 常数项: $(ax_1 + 2cy_1 + 2bz_1)$
* $\alpha$ 的系数: $(bx_1 + ay_1 + 2cz_1)$
* $\alpha^2$ 的系数: $(cx_1 + by_1 + az_1)$

要使上式等于 $1$（即 $1 + 0\alpha + 0\alpha^2$），必须满足以下线性方程组：


$$\begin{cases} ax_1 + 2cy_1 + 2bz_1 = 1 \\ bx_1 + ay_1 + 2cz_1 = 0 \\ cx_1 + by_1 + az_1 = 0 \end{cases}$$

写成矩阵形式为 $\mathbf{M} \mathbf{v} = \mathbf{e}$：


$$\begin{pmatrix} a & 2c & 2b \\ b & a & 2c \\ c & b & a \end{pmatrix} \begin{pmatrix} x_1 \\ y_1 \\ z_1 \end{pmatrix} = \begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix}$$

**第二步：证明矩阵 $\mathbf{M}$ 可逆**
要保证方程组有唯一解（且解在有理数集 $\mathbb{Q}$ 中），我们需要证明系数矩阵 $\mathbf{M}$ 的行列式不为零，即 $\det(\mathbf{M}) \neq 0$。

计算矩阵 $\mathbf{M}$ 的行列式：


$$\det(\mathbf{M}) = a(a^2 - 2bc) - 2c(ab - 2c^2) + 2b(b^2 - ac)$$

$$\det(\mathbf{M}) = a^3 - 2abc - 2abc + 4c^3 + 2b^3 - 2abc$$

$$\det(\mathbf{M}) = a^3 + 2b^3 + 4c^3 - 6abc$$

我们需要证明：当 $a,b,c \in \mathbb{Q}$ 不全为 $0$ 时，$a^3 + 2b^3 + 4c^3 - 6abc \neq 0$。
这里通常使用**无穷递降法（或奇偶性反证法）**：

假设存在不全为 $0$ 的有理数使得 $a^3 + 2b^3 + 4c^3 - 6abc = 0$。
我们可以将 $a,b,c$ 乘上它们分母的最小公倍数，转化为整数。因此，不妨假设存在不全为 $0$ 的**整数**解 $(a,b,c)$，并且假设它们没有非 $1$ 的公因子（即 $\gcd(a,b,c)=1$）。

在等式 $a^3 + 2b^3 + 4c^3 - 6abc = 0$ 中：

1. 因为 $2b^3$、$4c^3$ 和 $-6abc$ 都是偶数，所以 $a^3$ 必须是偶数，这意味着 $a$ 必须是偶数。
2. 设 $a = 2a_1$ 代入原式得：$8a_1^3 + 2b^3 + 4c^3 - 12a_1bc = 0$。
3. 两边同除以 $2$ 得到：$4a_1^3 + b^3 + 2c^3 - 6a_1bc = 0$。
4. 同理，由上式可知 $b^3$ 必须是偶数，所以 $b$ 也是偶数。
5. 设 $b = 2b_1$ 代入并除以 $2$，又会得到 $2a_1^3 + 4b_1^3 + c^3 - 6a_1b_1c = 0$。
6. 同理，这要求 $c^3$ 必须是偶数，所以 $c$ 也是偶数。

由此得出 $a, b, c$ 全是偶数。但这与我们一开始假设的“$\gcd(a,b,c)=1$（互素）”相矛盾！
因此，唯一的有理数解是 $a = b = c = 0$。

**结论**
只要 $a,b,c$ 不全为 $0$，$\det(\mathbf{M}) \neq 0$ 恒成立。
这意味着系数矩阵 $\mathbf{M}$ 永远是可逆的。因此，线性方程组必有唯一解 $\begin{pmatrix} x_1, y_1, z_1 \end{pmatrix}^\top$。根据克莱姆法则（Cramer's Rule），由于矩阵的元素都是有理数，解出的 $x_1, y_1, z_1$ 也必定是有理数。

这证明了 $x^{-1} = x_1 + y_1\alpha + z_1\alpha^2 \in F$。
由于非零元素皆有逆元，且对加减乘封闭，**$F$ 构成一个数域**。证毕。

## 单扩张

$
\begin{aligned}
&th2.1:\\
&设\alpha 是域F上的n次代数元,\\
&则:\\
&(1)F(\alpha )=F[\alpha ]\\
&(2)F(\alpha )\cong F[x]/<f(x)>,f(x)是\alpha 在F上的极小多项式\\
&(3)1,\alpha,\cdots ,\alpha ^{n-1}是扩张F(\alpha)\supset F的一组基底\\
&且|F(\alpha):F|=n\\
&\\\\
&Prove:\\
&F[\alpha]=a_0+a_1\alpha+\cdots+a_{n-1}\alpha^{n-1}\\   
&设RHS=x\\
&只需证明x^{-1}\in F[x]\\
&Prove \quad x^{-1} \in F[\alpha] :\\
&\\
&任取非零元 \ x \in F[\alpha]\\
&则 \exists g(t) \in F[t], \ s.t. \ x = g(\alpha)\\
&设 \ f(t) \ 是 \ \alpha \ 在F上的极小多项式, \ 则f(\alpha)=0\\
&\\
&因 \ x \neq 0, \ 故 \ g(\alpha) \neq 0\\
&即 \ f(t) \nmid g(t)\\
&又 \ f(t) \ 是不可约多项式\\
&故 \ \gcd(f(t), g(t)) = 1\\
&\\
&由裴蜀定理(B\acute{e}zout), \ \exists u(t), v(t) \in F[t], \ s.t.\\
&u(t)g(t) + v(t)f(t) = 1\\
&\\
&将 \ t = \alpha \ 代入上式, \ 得:\\
&u(\alpha)g(\alpha) + v(\alpha)f(\alpha) = 1\\
&\\
&因 \ f(\alpha) = 0, \ 故:\\
&u(\alpha)g(\alpha) = 1\\
&即 \ u(\alpha) \cdot x = 1\\
&\\
&故 \ x^{-1} = u(\alpha)\\
&由于 \ u(t) \in F[t], \ 显然 \ u(\alpha) \in F[\alpha]\\
&故证得 \ x^{-1} \in F[\alpha] \quad \blacksquare
\end{aligned}
$

## 分裂域和正规扩张

$
\begin{aligned}

&设\phi 是域F到\overline{F}的同构映射,\\
&f(x)是F[x]中的n次多项式,若E,\overline{E}分别是f(x),f^{\phi}(x)的分裂域\\

&\\\\
&P.S.\\
&若E是Z_{p}的有限扩域,则存在正整数n,s.t. |E|=p^{n}\\
&Prove:\\
&E是Z_{p}上的有限维线性空间,存在基\{v_1,\cdots ,v_{n}\}\\
&故E的任意元素x可以唯一的表示为\\

&(a-b)^{p^{n}}=a-b\\
&(ab^{-1})^{p^{n}}=ab^{-1}(b\ne 0)\\

&之后我们考虑证明|F|=p^{n}\\

&\\\\

&设E\supseteq F是有限扩张\\
