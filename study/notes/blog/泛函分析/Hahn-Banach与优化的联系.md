# Hahn–Banach 定理与优化方法的联系（草稿 / 待周末复盘系统学习）

> 状态：初步占位。完整推导、例题、习题计划在**本周末每周复盘**时补完。

## 0. 一句话定位

笔记 `Banach空间上的有界线性算子.md` 里读的 Hahn–Banach 是**分析型**（保范延拓）。
优化界天天用的是它的**几何型孪生兄弟：超平面分离定理**。两者本质是同一定理。

## 1. 分析型 → 几何型的桥梁：Minkowski 泛函（计量函数）

对含原点内部的凸集 $C$，定义
$$p_C(x)=\inf\{t>0: x\in tC\}.$$
它次线性（$p_C(x+y)\le p_C(x)+p_C(y)$），可当作定理 2.1/2.2 里的控制函数 $p$。
把"指向另一团凸集"的方向定义成在 $C$ 上 $\le 1$ 的线性泛函，再用 HB 延拓、被 $p_C$ 控制，
就得到分离两凸集的"墙" $F(x)=\alpha$。

**分离定理**：不相交凸集 $C_1,C_2$，若其一为开集，则存在非零连续线性泛函 $F$ 与 $\alpha$ 使
$$F(x_1)\le\alpha\le F(x_2),\quad \forall x_1\in C_1,\ x_2\in C_2.$$

## 2. 优化中的五大应用（框架）

1. **Farkas 引理**：$\,Ax=b,\ x\ge0$ 有解 $\iff$ 不存在 $y$ 使 $A^\top y\ge0$ 且 $b^\top y<0$。
   → 线性规划对偶、单纯形法检验数、不可行诊断的底层。
2. **次梯度 / 支撑超平面**：凸函数 $f$ 在 $x_0$ 处次梯度 $g$ 满足
   $f(x)\ge f(x_0)+g\cdot(x-x_0)$。这就是给上镜图一个支撑超平面（HB 保证存在）。
   最优性：$x_0$ 最优 $\iff 0\in\partial f(x_0)$。→ 次梯度法、proximal 方法的地基。
3. **KKT 条件**：带约束优化最优时存在乘子（对约束空间的线性泛函）满足
   平稳性、互补松弛、可行性。本质是"目标梯度落在约束法空间"，即存在支撑超平面。
4. **凸对偶 / 强对偶**：弱对偶不需 HB；强对偶（无对偶间隙）靠分离定理 + 约束规范保证。
   → 半定规划、锥规划、经济学影子价格。
5. **支撑超平面 / 投影**：点到凸集最近点、凸包刻画（"在凸包里" ⇔ "无泛函能单独分出去"）。

## 3. 与笔记已有概念的对应

- 控制函数 $p$（定理 2.1/2.2）→ 分离定理里的 Minkowski 泛函；最优性里的法向界。
- 连续线性泛函 $F/f$ → 优化里的**对偶变量、拉格朗日乘子、次梯度、影子价格**
  （对偶空间中的元素；HB 保证对偶空间"够稠密、够用"）。
