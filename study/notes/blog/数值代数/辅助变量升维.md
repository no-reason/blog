## 1. 问题与核心观察

2010 年丘赛应用与计算数学合卷第 5 题考虑

$$
(U_1U_2-\lambda I)x=b,\qquad U_1,U_2\in\mathbb R^{n\times n}\text{ 均为上三角矩阵},
$$

并假设 $U_1U_2-\lambda I$ 非奇异。要求**不显式构造矩阵乘积**，在 $O(n^2)$ 时间内求出 $x$；推广到 $p$ 个上三角矩阵时，目标为 $O(pn^2)$。

直接形成两个一般稠密上三角矩阵的乘积需要 $O(n^3)$ 运算，随后回代虽然只需 $O(n^2)$，但总成本仍为 $O(n^3)$。反过来，如果能直接得到该乘积的每一行，又必须避免重复计算大量乘积项。

**思路：不要算出 $U_1U_2$，而是保留中间向量 $y=U_2x$。** 这样虽然增加了未知变量，却保存了每个阶段本来要反复使用的信息。

> 注意：升维本身不保证提速。真正有效的是“辅助变量 + 上三角结构 + 按坐标从后向前消元”。

## 2. 原题第一问：分块矩阵恒等式

设

$$
S=\begin{pmatrix}\sigma&u^T\\0&S_c\end{pmatrix},\quad
T=\begin{pmatrix}\tau&v^T\\0&T_c\end{pmatrix},\quad
x=\begin{pmatrix}\gamma\\x_c\end{pmatrix},\quad
b=\begin{pmatrix}\beta\\b_c\end{pmatrix}.
$$

由于

$$
ST=\begin{pmatrix}
\sigma\tau&\sigma v^T+u^TT_c\\
0&S_cT_c
\end{pmatrix},
$$

方程 $(ST-\lambda I)x=b$ 等价于

$$
\begin{cases}
(\sigma\tau-\lambda)\gamma+(\sigma v^T+u^TT_c)x_c=\beta,\\
(S_cT_c-\lambda I)x_c=b_c.
\end{cases}
$$

如果已知后一个方程的解 $x_c$，并缓存 $w_c=T_cx_c$，那么

$$
\boxed{\gamma=\frac{\beta-\sigma v^Tx_c-u^Tw_c}{\sigma\tau-\lambda}.}
$$

这就解释了为什么原题特意给出 $w_c$：上一阶段计算出来的**中间乘积向量**，可以直接参与上一层的递归，不需要重算 $T_cx_c$。分母非零是该步回代的必要条件。

## 3. 两个上三角矩阵：直接构造 $O(n^2)$ 算法

令 $A=U_1=(a_{ij})$、$C=U_2=(c_{ij})$，引入

$$
y=Cx.
$$

原系统等价于

$$
\begin{cases}
Ay-\lambda x=b,\\
Cx-y=0.
\end{cases}
$$

也可以写成 $2n$ 维的稀疏块系统：

$$
\underbrace{\begin{pmatrix}-\lambda I&A\\C&-I\end{pmatrix}}_{2n\times2n}
\begin{pmatrix}x\\y\end{pmatrix}=\begin{pmatrix}b\\0\end{pmatrix}.
$$

**关键并不是对这个 $2n$ 维系统做普通高斯消元**；那样未必更快。要利用 $A,C$ 的上三角性。

对于 $i=n,n-1,\ldots,1$，先假设 $x_j,y_j\ (j>i)$ 都已算出。第 $i$ 行满足

$$
\begin{aligned}
a_{ii}y_i+\sum_{j=i+1}^n a_{ij}y_j-\lambda x_i&=b_i,\\
y_i&=c_{ii}x_i+\sum_{j=i+1}^n c_{ij}x_j.
\end{aligned}
$$

消去 $y_i$ 得

$$
\boxed{x_i=\frac{b_i-\displaystyle\sum_{j=i+1}^n a_{ij}y_j-a_{ii}\displaystyle\sum_{j=i+1}^n c_{ij}x_j}{a_{ii}c_{ii}-\lambda}.}
$$

再代回计算

$$
\boxed{y_i=c_{ii}x_i+\sum_{j=i+1}^n c_{ij}x_j.}
$$

由上三角矩阵乘积的对角元公式，

$$
\det(AC-\lambda I)=\prod_{i=1}^n(a_{ii}c_{ii}-\lambda).
$$

故题目假设非奇异恰好保证**每个分母都不为零**。

### 正确性（可直接用于考试的归纳证明）

对 $i$ 逆向归纳。假设对所有 $j>i$，已经算出了满足原系统相应行的 $x_j,y_j$。在第 $i$ 行，上三角结构保证只出现 $x_i,y_i$ 与这些已知坐标。由非零分母可唯一解出 $x_i$，再唯一求出 $y_i$，使两条第 $i$ 行方程同时成立。直到 $i=1$，全部 $2n$ 条方程成立，所求 $x$ 即为原系统的唯一解。

### 复杂度

第 $i$ 步只需要两个长度不超过 $n-i$ 的内积，其余是常数次标量运算：

$$
T(n)=\sum_{i=1}^nO(n-i+1)=O(n^2).
$$

输入矩阵本身占 $O(n^2)$ 空间；除输入之外只需额外存储 $x,y$ 两个 $n$ 维向量，辅助空间为 $O(n)$。

### C++17：两矩阵版本（可直接编译）

示例输入约定：第一行 `n lambda`，接着各 $n$ 行的 $U_1$、$U_2$，最后一行向量 $b$。为了简单，代码直接读取完整矩阵。

```cpp
#include <bits/stdc++.h>
using namespace std;
using ld = long double;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; ld lambda;
    cin >> n >> lambda;
    vector<vector<ld>> A(n, vector<ld>(n)), C(n, vector<ld>(n));
    for (int i = 0; i < n; ++i)
        for (int j = 0; j < n; ++j) cin >> A[i][j];
    for (int i = 0; i < n; ++i)
        for (int j = 0; j < n; ++j) cin >> C[i][j];
    vector<ld> b(n), x(n), y(n);
    for (auto &v : b) cin >> v;

    for (int i = n - 1; i >= 0; --i) {
        ld sA = 0, sC = 0;
        for (int j = i + 1; j < n; ++j) {
            sA += A[i][j] * y[j];
            sC += C[i][j] * x[j];
        }
        ld pivot = A[i][i] * C[i][i] - lambda;
        // 理论上非零；输入若接近奇异，浮点计算可能不稳定。
        x[i] = (b[i] - sA - A[i][i] * sC) / pivot;
        y[i] = C[i][i] * x[i] + sC;
    }

    cout << fixed << setprecision(12);
    for (int i = 0; i < n; ++i)
        cout << x[i] << (i + 1 == n ? '\n' : ' ');
}
```

## 4. 推广：$p$ 个上三角矩阵的 $O(pn^2)$ 算法

现在解

$$
(U_1U_2\cdots U_p-\lambda I)x=b.
$$

定义 $p$ 级辅助向量（从右向左依次相乘）：

$$
z^{(p+1)}=x,\qquad z^{(r)}=U_rz^{(r+1)},\quad r=p,p-1,\ldots,1.
$$

于是 $z^{(1)}-\lambda x=b$。设 $U_r=(u_{ij}^{(r)})$。固定坐标 $i$，对每个 $r$ 定义已知尾项

$$
h_r(i)=\sum_{j=i+1}^{n}u_{ij}^{(r)}z_j^{(r+1)}.
$$

因为我们按 $i=n,n-1,\ldots,1$ 处理，所以尾项都能直接计算。现在每一级仅剩

$$
z_i^{(r)}=u_{ii}^{(r)}z_i^{(r+1)}+h_r(i).
$$

暂时将 $x_i$ 当作待定参数，写作

$$
z_i^{(r)}=d_rx_i+c_r.
$$

初值是 $d_{p+1}=1,c_{p+1}=0$；从 $r=p$ 递推到 $1$：

$$
\boxed{
\begin{aligned}
d_r&=u_{ii}^{(r)}d_{r+1},\\
c_r&=u_{ii}^{(r)}c_{r+1}+h_r(i).
\end{aligned}}
$$

把 $z_i^{(1)}-\lambda x_i=b_i$ 代入：

$$
\boxed{x_i=\frac{b_i-c_1}{d_1-\lambda}},\qquad
\boxed{d_1=\prod_{r=1}^p u_{ii}^{(r)}}.
$$

得到 $x_i$ 后，再从 $r=p$ 向 $1$ 代回，存好所有的 $z_i^{(r)}$，供计算下一坐标时复用。

**复杂度**：在坐标 $i$ 上计算 $p$ 个尾项需要 $O(p(n-i))$，再进行 $O(p)$ 次系数递推及回代。于是

$$
\boxed{T(n,p)=\sum_{i=1}^nO(p(n-i+1))=O(pn^2).}
$$

保留所有辅助向量仅需 $O(pn)$ 额外空间。由于矩阵乘积仍是上三角矩阵，非奇异性保证 $\prod_r u_{ii}^{(r)}-\lambda\neq0$。

### C++17：一般 $p$ 矩阵版本（核心函数）

下列函数输入 $p$ 个完整上三角矩阵；`z[r][i]` 存储第 $r$ 级的已知坐标（代码使用 0-based 级数）。

```cpp
#include <bits/stdc++.h>
using namespace std;
using ld = long double;
using Mat = vector<vector<ld>>;

vector<ld> solve_product(const vector<Mat>& U, ld lambda,
                         const vector<ld>& b) {
    int p = (int)U.size(), n = (int)b.size();
    vector<vector<ld>> z(p + 1, vector<ld>(n, 0));
    vector<ld> tail(p), d(p + 1), c(p + 1);

    for (int i = n - 1; i >= 0; --i) {
        for (int r = 0; r < p; ++r) {
            tail[r] = 0;
            for (int j = i + 1; j < n; ++j)
                tail[r] += U[r][i][j] * z[r + 1][j];
        }
        d[p] = 1; c[p] = 0;
        for (int r = p - 1; r >= 0; --r) {
            d[r] = U[r][i][i] * d[r + 1];
            c[r] = U[r][i][i] * c[r + 1] + tail[r];
        }
        z[p][i] = (b[i] - c[0]) / (d[0] - lambda);
        for (int r = p - 1; r >= 0; --r)
            z[r][i] = U[r][i][i] * z[r + 1][i] + tail[r];
    }
    return z[p]; // 即 x
}
```

## 5. 为什么这不等于一般的“升维就提速”？

对于任意稠密 $A,C$，即使引入 $y=Cx$，第 $i$ 行也包含 $j<i$ 的未知坐标，无法直接从后向前求解。于是“升维”仅仅改写了系统，没有消除难点。

真正可复用的模式是：

$$
\boxed{\text{复杂算子乘积}\ \to\ \text{辅助中间状态}\ \to\ \text{结构化依赖}\ \to\ \text{顺序消元}.}
$$

类似的思想见于动态规划中的状态扩充、计算图中的中间节点缓存、控制问题中的状态空间实现，以及块三角线性系统的求解。

1. 为什么题目给出 $w_c=T_cx_c$，而不仅仅给出 $x_c$？请从避免重复运算解释。
2. 如果 $\lambda=0$，是否仍可用同一算法？哪些非零条件会自动成立？
3. 若 $U_r$ 全部换成下三角矩阵，消元方向应如何改变？
4. 设一部分 $U_r$ 为带状上三角矩阵，能否进一步得到 $O(pnk)$ 的复杂度？需要哪些带宽假设？
5. 当 $\prod_r u_{ii}^{(r)}$ 非常接近 $\lambda$ 时，即便数学上可逆，浮点误差是否可能被放大？

**考试时最值得记住的结论**：引入 $y=U_2x$ 或 $z^{(r)}=U_rz^{(r+1)}$，在每个坐标上先利用大下标的已知部分，解一个小规模标量方程；倒序归纳证明正确性，内积长度求和证明复杂度。
