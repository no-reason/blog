## 运算符

MATLAB 中的运算符大致可以分为：算术运算符、关系运算符、逻辑运算符、赋值运算符和一些常用的特殊运算符。

### 1. 算术运算符

| 运算符 | 含义 | 示例 |
| --- | --- | --- |
| `+` | 加法 | `a + b` |
| `-` | 减法 | `a - b` |
| `*` | 矩阵乘法 | `A * B` |
| `/` | 右除 | `A / B` |
| `\` | 左除 | `A \ B` |
| `^` | 矩阵幂 | `A ^ 2` |
| `.'` | 转置 | `A.'` |
| `'` | 共轭转置 | `A'` |

需要注意的是，MATLAB 默认按照矩阵运算规则计算。如果要对数组中的每个元素分别运算，需要使用点运算符。

| 运算符 | 含义 | 示例 |
| --- | --- | --- |
| `.*` | 对应元素相乘 | `A .* B` |
| `./` | 对应元素右除 | `A ./ B` |
| `.\` | 对应元素左除 | `A .\ B` |
| `.^` | 对应元素乘方 | `A .^ 2` |

示例：

```matlab
A = [1 2; 3 4];
B = [5 6; 7 8];

A * B      % 矩阵乘法
A .* B     % 对应位置元素相乘
A ^ 2      % 矩阵平方，相当于 A * A
A .^ 2     % 每个元素分别平方
```

### 2. 关系运算符

关系运算符用于比较两个数、数组或矩阵，结果为逻辑值 `1` 或 `0`，分别表示真和假。

| 运算符 | 含义 | 示例 |
| --- | --- | --- |
| `==` | 等于 | `a == b` |
| `~=` | 不等于 | `a ~= b` |
| `>` | 大于 | `a > b` |
| `<` | 小于 | `a < b` |
| `>=` | 大于等于 | `a >= b` |
| `<=` | 小于等于 | `a <= b` |

示例：

```matlab
x = [1 2 3 4];
x > 2
% 结果：[0 0 1 1]
```

关系运算常用于筛选数组元素：

```matlab
x = [1 2 3 4];
y = x(x > 2);
% y = [3 4]
```

### 3. 逻辑运算符

逻辑运算符用于连接或取反逻辑表达式。

| 运算符 | 含义 | 说明 |
| --- | --- | --- |
| `&` | 逻辑与 | 两边都为真时结果为真 |
| `\|` | 逻辑或 | 至少一边为真时结果为真 |
| `~` | 逻辑非 | 取反 |
| `&&` | 短逻辑与 | 只用于标量逻辑表达式 |
| `\|\|` | 短逻辑或 | 只用于标量逻辑表达式 |

示例：

```matlab
x = [1 2 3 4];

(x > 1) & (x < 4)
% 结果：[0 1 1 0]
```

`&` 和 `|` 可以用于数组逐元素逻辑运算；`&&` 和 `||` 常用于 `if`、`while` 等语句中的标量判断。

```matlab
a = 3;
b = 5;

if a > 0 && b > 0
    disp("a 和 b 都是正数")
end
```

### 4. 赋值运算符

MATLAB 使用 `=` 进行赋值。

```matlab
a = 10;
b = [1 2 3];
A = [1 2; 3 4];
```

注意：`=` 是赋值，`==` 才是判断是否相等。

```matlab
a = 3;      % 把 3 赋值给 a
a == 3     % 判断 a 是否等于 3
```

### 5. 冒号运算符

冒号 `:` 是 MATLAB 中非常常用的运算符，可以用来生成向量、指定步长、提取数组或矩阵的一部分。

```matlab
1:5
% 结果：[1 2 3 4 5]

1:2:9
% 结果：[1 3 5 7 9]
```

提取矩阵元素：

```matlab
A = [1 2 3; 4 5 6; 7 8 9];

A(:, 2)     % 取第 2 列
A(1, :)     % 取第 1 行
A(1:2, :)   % 取第 1 到第 2 行
```

### 6. 运算优先级

常见运算符优先级从高到低大致如下：

1. 括号 `()`
2. 转置 `'`、点转置 `.'`、乘方 `^`、点乘方 `.^`
3. 一元加减 `+a`、`-a`、逻辑非 `~`
4. 乘除 `*`、`/`、`\`、`.*`、`./`、`.\`
5. 加减 `+`、`-`
6. 冒号 `:`
7. 关系运算符 `>`、`<`、`>=`、`<=`、`==`、`~=`
8. 逻辑与 `&`
9. 逻辑或 `|`
10. 短路逻辑与 `&&`
11. 短路逻辑或 `||`

为了让表达式更清晰，建议在复杂表达式中主动使用括号。

```matlab
result = (a + b) * c;
```

### 7. 常见易错点

1. 矩阵运算和元素运算不要混淆：

```matlab
A * B      % 矩阵乘法
A .* B     % 元素乘法
```

2. 判断相等时使用 `==`，不要写成 `=`：

```matlab
if a == b
    disp("a 等于 b")
end
```

3. 对数组进行条件筛选时，逻辑表达式要加括号：

```matlab
x((x > 1) & (x < 5))
```

4. 复数矩阵中，`'` 是共轭转置，`.'` 才是不共轭的普通转置：

```matlab
z = [1 + 2i, 3 + 4i];

z'      % 共轭转置
z.'     % 普通转置
```

## help 命令

`help` 是 MATLAB 中查看函数、命令、工具箱说明的常用命令。

### 1. 查看某个函数的帮助

```matlab
help 函数名
```

示例：

```matlab
help plot
help sin
help mean
```

执行后，命令行窗口会显示该函数的基本用法、参数说明和相关函数。

### 2. 查看某个主题的帮助

```matlab
help 主题名
```

示例：

```matlab
help operators
help elfun
help graphics
```

其中：

| 命令 | 含义 |
| --- | --- |
| `help operators` | 查看 MATLAB 运算符说明 |
| `help elfun` | 查看基本数学函数 |
| `help graphics` | 查看绘图相关内容 |

### 3. 查看当前文件夹或工具箱中的帮助

直接输入 `help` 可以查看当前路径下可用的帮助主题。

```matlab
help
```

如果某个文件夹中有多个 `.m` 文件，MATLAB 也可以显示这些文件的说明信息。

### 4. help 和 doc 的区别

| 命令 | 作用 | 显示位置 |
| --- | --- | --- |
| `help 函数名` | 查看简短文字说明 | 命令行窗口 |
| `doc 函数名` | 打开更完整的官方文档 | 帮助浏览器 |

示例：

```matlab
help plot
doc plot
```

一般来说，快速查语法可以用 `help`，想看完整示例和详细解释可以用 `doc`。

### 5. 自定义函数的 help 说明

自己写 `.m` 文件时，可以在函数开头写注释。之后使用 `help` 命令时，MATLAB 会显示这些开头注释。

例如，新建文件 `myadd.m`：

```matlab
function c = myadd(a, b)
% MYADD 计算两个数的和
%   c = MYADD(a, b) 返回 a 和 b 的和。

c = a + b;
end
```

在命令行输入：

```matlab
help myadd
```

会显示：

```matlab
MYADD 计算两个数的和
  c = MYADD(a, b) 返回 a 和 b 的和。
```

### 6. 常用相关命令

| 命令 | 含义 |
| --- | --- |
| `help 函数名` | 查看函数的简要帮助 |
| `doc 函数名` | 打开函数的详细文档 |
| `lookfor 关键词` | 按关键词搜索相关函数 |
| `which 函数名` | 查看函数文件的位置 |
| `type 函数名` | 在命令行显示函数源码 |

示例：

```matlab
lookfor inverse

type mean
```

# 数值运算

## 向量及其运算

向量可以看成一维数组，在 MATLAB 中分为行向量和列向量。

### 1. 创建向量

```matlab
a = [1 2 3 4];      % 行向量
b = [1; 2; 3; 4];   % 列向量
```

也可以使用冒号 `:` 创建等差向量。

```matlab
x = 1:5
% x = [1 2 3 4 5]

y = 1:2:9
% y = [1 3 5 7 9]
```

常用生成函数：

| 函数 | 含义 | 示例 |
| --- | --- | --- |
| `linspace(a, b, n)` | 在 `a` 到 `b` 之间生成 `n` 个等间距点 | `linspace(0, 1, 5)` |
| `zeros(1, n)` | 生成全 0 行向量 | `zeros(1, 4)` |
| `ones(1, n)` | 生成全 1 行向量 | `ones(1, 4)` |
| `rand(1, n)` | 生成随机行向量 | `rand(1, 4)` |

示例：

```matlab
linspace(0, 10, 6)
% 结果：[0 2 4 6 8 10]
```

### 2. 访问向量元素

MATLAB 的下标从 `1` 开始。

```matlab
x = [10 20 30 40 50];

x(1)        % 第 1 个元素
x(3)        % 第 3 个元素
x(2:4)      % 第 2 到第 4 个元素
x(end)      % 最后一个元素
```

### 3. 向量的基本运算

如果两个向量长度相同，可以进行对应元素的运算。

```matlab
a = [1 2 3];
b = [4 5 6];

a + b       % [5 7 9]
a - b       % [-3 -3 -3]
a .* b      % [4 10 18]
a ./ b      % [0.25 0.4 0.5]
a .^ 2      % [1 4 9]
```

注意：`*` 表示矩阵乘法，`.*` 才是对应元素相乘。

### 4. 向量点积和叉积

点积：

```matlab
a = [1 2 3];
b = [4 5 6];

dot(a, b)
% 结果：32
```

也可以用矩阵乘法表示点积：

```matlab
a * b'
```

叉积只适用于三维向量：

```matlab
cross([1 0 0], [0 1 0])
% 结果：[0 0 1]
```

### 5. 向量常用函数

| 函数 | 含义 |
| --- | --- |
| `length(x)` | 向量长度 |
| `sum(x)` | 元素求和 |
| `prod(x)` | 元素连乘 |
| `max(x)` | 最大值 |
| `min(x)` | 最小值 |
| `mean(x)` | 平均值 |
| `sort(x)` | 排序 |
| `norm(x)` | 向量范数 |

示例：

```matlab
x = [3 1 4 2];

sum(x)
mean(x)
sort(x)
norm(x)
```

## 矩阵及其运算

矩阵是 MATLAB 最核心的数据类型之一。MATLAB 这个名字本身就来自 Matrix Laboratory。

### 1. 创建矩阵

矩阵用方括号 `[]` 创建，同一行的元素用空格或逗号分隔，不同行之间用分号 `;` 分隔。

```matlab
A = [1 2 3; 4 5 6; 7 8 9];
```

常用矩阵生成函数：

| 函数 | 含义 | 示例 |
| --- | --- | --- |
| `zeros(m, n)` | 生成 `m` 行 `n` 列的全 0 矩阵 | `zeros(2, 3)` |
| `ones(m, n)` | 生成全 1 矩阵 | `ones(2, 3)` |
| `eye(n)` | 生成 `n` 阶单位矩阵 | `eye(3)` |
| `rand(m, n)` | 生成随机矩阵 | `rand(2, 3)` |
| `magic(n)` | 生成 `n` 阶魔方矩阵 | `magic(3)` |

### 2. 访问矩阵元素

矩阵元素使用 `A(行, 列)` 访问。

```matlab
A = [1 2 3; 4 5 6; 7 8 9];

A(1, 2)     % 第 1 行第 2 列元素，结果为 2
A(:, 1)     % 第 1 列
A(2, :)     % 第 2 行
A(1:2, 2:3) % 第 1 到 2 行、第 2 到 3 列
A(end, end) % 最后一行最后一列元素
```

### 3. 矩阵基本运算

```matlab
A = [1 2; 3 4];
B = [5 6; 7 8];

A + B       % 矩阵加法
A - B       % 矩阵减法
A * B       % 矩阵乘法
A .* B      % 对应元素相乘
A / B       % 右除，相当于 A * inv(B)
A \ B       % 左除，相当于求解 A * X = B
A ^ 2       % 矩阵乘方，相当于 A * A
A .^ 2      % 每个元素分别平方
```

矩阵乘法要求前一个矩阵的列数等于后一个矩阵的行数。

```matlab
A = [1 2 3; 4 5 6];    % 2 行 3 列
B = [1 2; 3 4; 5 6];    % 3 行 2 列

C = A * B               % 结果是 2 行 2 列矩阵
```

### 4. 矩阵转置

```matlab
A = [1 2 3; 4 5 6];

A.'     % 普通转置
A'      % 共轭转置
```

如果矩阵中没有复数，`A.'` 和 `A'` 的结果相同；如果含有复数，`A'` 会同时进行转置和共轭。

### 5. 矩阵常用函数

| 函数 | 含义 |
| --- | --- |
| `size(A)` | 查看矩阵行数和列数 |
| `length(A)` | 返回最大维度的长度 |
| `numel(A)` | 元素总数 |
| `det(A)` | 行列式 |
| `inv(A)` | 逆矩阵 |
| `rank(A)` | 矩阵的秩 |
| `trace(A)` | 主对角线元素之和 |
| `diag(A)` | 提取或生成对角线 |
| `reshape(A, m, n)` | 改变矩阵形状 |

示例：

```matlab
A = [1 2; 3 4];

size(A)
det(A)
inv(A)
rank(A)
trace(A)
```

### 6. diag(v, k) 的用法

`diag` 既可以从矩阵中提取对角线元素，也可以根据向量生成对角矩阵。

```matlab
v = [1 2 3];

diag(v)
```

结果是：

```matlab
     1     0     0
     0     2     0
     0     0     3
```

`diag(v, k)` 可以把向量 `v` 放到第 `k` 条对角线上。

| 写法 | 含义 |
| --- | --- |
| `diag(v, 0)` | 放在主对角线，和 `diag(v)` 相同 |
| `diag(v, 1)` | 放在主对角线上方第 1 条对角线 |
| `diag(v, 2)` | 放在主对角线上方第 2 条对角线 |
| `diag(v, -1)` | 放在主对角线下方第 1 条对角线 |
| `diag(v, -2)` | 放在主对角线下方第 2 条对角线 |

示例：

```matlab
v = [1 2 3];

diag(v, 1)
```

结果是：

```matlab
     0     1     0     0
     0     0     2     0
     0     0     0     3
     0     0     0     0
```

```matlab
diag(v, -1)
```

结果是：

```matlab
     0     0     0     0
     1     0     0     0
     0     2     0     0
     0     0     3     0
```

如果 `diag` 的输入是矩阵，则表示提取指定对角线上的元素。

```matlab
A = [1 2 3; 4 5 6; 7 8 9];

diag(A)       % 提取主对角线，结果为 [1; 5; 9]
diag(A, 1)    % 提取主对角线上方第 1 条对角线，结果为 [2; 6]
diag(A, -1)   % 提取主对角线下方第 1 条对角线，结果为 [4; 8]
```

### 7. sparse 的用法

`sparse` 用来创建稀疏矩阵。稀疏矩阵适合存储大部分元素都是 `0` 的矩阵，可以节省内存和提高部分运算效率。

普通矩阵会把所有元素都存下来，包括大量的 `0`；稀疏矩阵主要存储非零元素的位置和值。

### 7.1 将普通矩阵转换为稀疏矩阵

```matlab
A = [0 0 3; 0 5 0; 7 0 0];

S = sparse(A)
```

结果会显示非零元素的位置和值：

```matlab
   (3,1)        7
   (2,2)        5
   (1,3)        3
```

其中 `(3,1) 7` 表示第 `3` 行第 `1` 列的元素是 `7`。

### 7.2 根据行、列和值创建稀疏矩阵

`sparse(i, j, v)` 可以根据非零元素的位置和值创建稀疏矩阵。

```matlab
i = [1 2 3];       % 行下标
j = [3 2 1];       % 列下标
v = [3 5 7];       % 对应位置的值

S = sparse(i, j, v)
```

生成的矩阵相当于：

```matlab
     0     0     3
     0     5     0
     7     0     0
```

也可以指定矩阵大小：

```matlab
S = sparse(i, j, v, 4, 5)
```

表示生成一个 `4` 行 `5` 列的稀疏矩阵。

### 7.3 查看稀疏矩阵的信息

常用函数：

| 函数 | 含义 |
| --- | --- |
| `full(S)` | 把稀疏矩阵转换为普通矩阵 |
| `nnz(S)` | 统计非零元素个数 |
| `issparse(S)` | 判断是否为稀疏矩阵 |
| `spy(S)` | 用图形显示矩阵中非零元素的位置 |

示例：

```matlab
full(S)         % 转换为普通矩阵
nnz(S)          % 非零元素个数
issparse(S)     % 判断 S 是否为稀疏矩阵
spy(S)          % 显示非零元素分布
```

### 7.4 稀疏单位矩阵

`speye(n)` 可以创建 `n` 阶稀疏单位矩阵。

```matlab
I = speye(4)
```

它和 `eye(4)` 的数学含义一样，都是单位矩阵；区别是 `speye(4)` 生成的是稀疏矩阵。

### 7.5 使用场景

当矩阵规模很大，并且大部分元素都是 `0` 时，适合使用稀疏矩阵。

例如：

```matlab
A = zeros(1000, 1000);
A(1, 1) = 5;
A(500, 500) = 8;
A(1000, 1000) = 3;

S = sparse(A);
```

这个矩阵有 `1000000` 个元素，但只有 `3` 个非零元素，用 `sparse` 存储会更节省空间。

### 8. 解线性方程组

对于线性方程组：

```matlab
A * x = b
```

推荐使用左除 `\` 求解，而不是手动求逆。

```matlab
A = [2 1; 1 3];
b = [3; 4];

x = A \ b
```

这比 `inv(A) * b` 更快、更稳定。

## 多项式及其运算

在 MATLAB 中，多项式通常用系数向量表示，并且按照降幂排列。

例如：

```matlab
p = [1 2 3];
```

表示多项式：

```matlab
x^2 + 2x + 3
```

再如：

```matlab
p = [2 0 -5 1];
```

表示：

```matlab
2x^3 - 5x + 1
```

其中缺少的 `x^2` 项要用系数 `0` 占位。

### 1. 多项式求值

使用 `polyval` 计算多项式在某个点的值。

```matlab
p = [1 2 3];     % x^2 + 2x + 3

y = polyval(p, 2)
% y = 11
```

也可以对一组 `x` 同时求值。

```matlab
x = 0:5;
y = polyval(p, x);
```

### 2. 多项式求根

使用 `roots` 求多项式的根。

```matlab
p = [1 -3 2];    % x^2 - 3x + 2

r = roots(p)
% 结果为 1 和 2
```

### 3. 由根生成多项式

使用 `poly` 可以由根生成多项式系数。

```matlab
r = [1 2];
p = poly(r)
% p = [1 -3 2]
```

### 4. 多项式加减

多项式加减本质上是系数相加减。如果两个多项式次数不同，需要先补 0，使系数向量长度相同。

```matlab
p1 = [1 2 3];       % x^2 + 2x + 3
p2 = [4 5];         % 4x + 5

p2 = [0 p2];        % 补成 0x^2 + 4x + 5

p_add = p1 + p2
p_sub = p1 - p2
```

### 5. 多项式乘法

使用 `conv` 进行多项式乘法。

```matlab
p1 = [1 2];         % x + 2
p2 = [1 3];         % x + 3

p = conv(p1, p2)
% p = [1 5 6]，表示 x^2 + 5x + 6
```

### 6. 多项式除法

使用 `deconv` 进行多项式除法。

```matlab
p = [1 5 6];        % x^2 + 5x + 6
q = [1 2];          % x + 2

[quotient, remainder] = deconv(p, q)
% quotient = [1 3]
% remainder = [0 0 0]
```

其中 `quotient` 是商，`remainder` 是余式。

### 7. 多项式求导

使用 `polyder` 求多项式导数。

```matlab
p = [3 2 1];        % 3x^2 + 2x + 1

dp = polyder(p)
% dp = [6 2]，表示 6x + 2
```

### 8. 多项式拟合

使用 `polyfit` 可以根据数据点拟合多项式。

```matlab
x = [1 2 3 4];
y = [2 5 10 17];

p = polyfit(x, y, 2)
```

上面代码表示用二次多项式拟合数据点。拟合后可以用 `polyval` 计算拟合曲线上的值。

```matlab
x_fit = 1:0.1:4;
y_fit = polyval(p, x_fit);

plot(x, y, 'o', x_fit, y_fit, '-')
```
